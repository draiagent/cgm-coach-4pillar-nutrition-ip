# 四養膳法：框架與應用

## 定義

以「酵、蛋、纖、菌」作為每日飲食討論的四個入口，配合 A → A+ → S 的生活、營養與數據循環。四柱為品牌整理方式，不主張涵蓋所有營養需求，也不預設每個人都需購買四類補充品。

## 每日記錄範例

| 觀察入口 | 可記錄內容 | 回顧問題 |
|---|---|---|
| 酵 | 第一餐吃了什麼、用餐感受 | 第一餐是否有規劃？ |
| 蛋 | 各餐蛋白質食物來源 | 是否只集中在某一餐？ |
| 纖 | 蔬菜、全穀、豆類等食物紀錄 | 飲食來源是否多樣？ |
| 菌 | 發酵食品或益生菌產品紀錄 | 記錄的是食物、菌株產品，還是菌相概念？ |

這是紀錄模板，不是個人化飲食處方。

## 知識到行動

1. 記錄生活與飲食現況。
2. 以四柱整理問題，選擇一項可執行的生活行動。
3. 記錄主觀感受與可用數據。
4. 定期回顧，不把單次數據變化當作產品效果證明。

## AI Agent 延伸規格（規劃中）

輸入：使用者主動提供的飲食紀錄、行動目標與可選數據。  
處理：整理四柱內容、標註缺失資料、提出回顧問題。  
輸出：每日紀錄與待確認事項。  
界線：不自行診斷、調藥或判定產品療效；本儲存庫尚未實作 Agent、資料串接或健康資料儲存系統。
